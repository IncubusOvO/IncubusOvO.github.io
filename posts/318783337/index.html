这是之前在dc靶场的设置中查看到的mac地址

扫到了靶场的ip

扫描目标主机开放端口

发展22端口和80端口是开着的，80是http协议

浏览器访问192.168.231.131

用浏览器插件识别出CMS是Drupal

或者用kali自带的工具也可以扫出来

用dirsearch工具扫描目录

目录有点多，先让他扫着，看看cms有没有可以利用的漏洞

2.漏洞查找与利用

搜 Drupla 发现有框架漏洞

用metasploit渗透测试工具找一下漏洞

先打开工具

搜索drupal板块

选一个时间最新且危害等级最高的

有些信息需要配置

缺少RHOSTS信息（目标ip，这里填靶机ip）

设好之后就可以开始攻击了

出现这个说明攻击成功了

3.拿shell（命令行）

输入ls，发现一个flag1.txt

得到第一个flag：Every good CMS needs a config file - and so do you.

翻译过来就是提示我们找一个配置文件

然后利用python实现交互式shell（一般kali自带python环境）

交互式shell好处：

这个 pty 模块的全称就是 Pseudo-Terminal（伪终端）。
它的作用就是：骗系统。告诉系统“我是一个分配了 TTY 的终端”，从而让你的 Bash 重新拥有 Tab 补全、方向键和能执行 su 的能力。但光让系统以为是还不够，你本地的终端也需要配合调整。

找配置文件

觉得这样太麻烦也可以用find命令

找到flag2以及数据库配置信息

提示我们要获得高级权限

4.数据库渗透

用上面找到的账号密码登录一下

登陆成功，查一下数据库名

看到一个特殊的数据库drupaldb，切换数据库，并查询表名

找到一个uses表，看一下内容

如果嫌这种显示效果太难看的可以加个\G

这样正常多了，一开始那个表格显示不正常可能是字体原因

可以看到admin和Fred的密码并没有以明文方式存储

我们要通过修改账户密码来进行登录，不过这个是下策了，一般是先破解hash密码

所以这里只能找找看加密脚本然后再进行修改了

scripts是一脚本文件

查看一下password-hash.sh

代码审计一下

这个脚本是用php写的，而且还能用php加参数运行，直接得到加密后的密码，这里我们设置一个密码123456

得到加密后的密码

hash: $S$DgUfvBiuwNI22pbQdIDOA1shJ9aFxQGfui7tdUEV1kQqKRS4JCId

然后去数据库修改那两个用户的密码

去网页登录一下

找到flag3了

提示了我们一些信息passwd和shadow，其实就是 linux 的文件

然后就去翻一下etc/passwd这个文件

5.提权

发现一个flag4账户

密码果然被加密锁起来了，现在需要找到具有SUID的命令提权然后访问etc/shadow

使用find命令找到具有SUID权限的可执行二进制文件

用find命令，因为它比较常用，它可以执行root权限的命令查找文件

  • **find**：调用查找文件的程序。
  • **/**：从系统的根目录开始找（全盘搜索）。
  • **-name index.php**：查找名字叫 index.php 的文件。（注意：这部分其实不重要！ 随便找个存在的文件，哪怕是 -name test 都行，它只是触发后面动作的一个“条件”或“借口”）。
  • **-exec**：这是 find 的一个强大参数。意思是：“对前面找到的每一个文件，执行后面的命令”。
  • **"/bin/sh"**：这就是被执行的命令。启动一个 sh 命令解释器（也就是我们前面说的 Shell）。
  • **\;**：这是 -exec 参数的结束符。必须加反斜杠 \ 进行转义，告诉 bash 解释器“这个分号是给 find 用的，不是给你用的”。

提权成功了
